⚡ Quickstart: Solving TypeScript Challenges

1. Install Dependencies

Ensure Node.js 18+ is installed. Install local dependencies for type checking.

pnpm install || npm install

2. Open Any Question

Questions are located in questions/<number>-<tier>-<name>/template.ts.

cd questions/00004-easy-pick

3. Verify Your Type Solution

Run the TypeScript compiler to ensure all @type-challenges/utils test assertions pass.

npm test
