⚡ Quickstart: Running Exercises

1. Activate Environment

Ensure Python 3.14 or 3.12+ is in your PATH. Optionally create a virtual environment for the track.

python -m venv .venv

2. Install Test Runner

Exercism Python exercises use pytest for automated unit testing and validation.

pip install pytest

3. Run Any Exercise Test

Navigate to any exercise directory inside exercises/Practice/<exercise-name> and run pytest.

pytest <exercise>_test.py
