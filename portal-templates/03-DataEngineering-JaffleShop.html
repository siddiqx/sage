⚡ Quickstart: Running dbt Locally

1. Install dbt-postgres or dbt-duckdb

Install the dbt adapter corresponding to your target database engine.

pip install dbt-duckdb

2. Seed Raw Data

Load the canonical CSV seeds (raw_customers.csv, raw_orders.csv, raw_payments.csv).

dbt seed

3. Build Dimensional Models

Compile and execute the SQL transformations to build staging and dimensional tables.

dbt run
