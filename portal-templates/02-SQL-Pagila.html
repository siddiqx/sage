⚡ Quickstart: Launching Postgres with Docker

1. Start Postgres & pgAdmin

Launch the pre-configured PostgreSQL 16 container with the Pagila dataset loaded automatically.

docker compose up -d

2. Connect via psql CLI

Connect directly into the running Postgres instance inside the container or from your local terminal.

psql -h localhost -U postgres -d pagila

3. Open Web UI (pgAdmin)

Access the browser-based pgAdmin interface at http://localhost:5050 (admin@pagila.local / pagila).
