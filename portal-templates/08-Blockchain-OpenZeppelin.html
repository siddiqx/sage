⚡ Quickstart: Compiling & Testing Contracts

1. Install Dependencies

Ensure Node.js 18+ is installed. Install repository package dependencies with npm or yarn.

npm install

2. Compile Solidity

Compile all Solidity 0.8+ smart contracts using the configured Hardhat pipeline.

npx hardhat compile

3. Run Test Suite

Execute the comprehensive Mocha/Chai test suite verifying contract security invariants.

npx hardhat test
